# Find the Bricks Pacman!
Projeto Unity para avaliação da matéria Programação em jogos

Nesse protótipo de jogo, Escolhemos o Pacman como nosso player, seu objetivo é encontrar blocos que estão espalhado pelo seu famoso labirinto do jogo 2d, agora visto em outra perspectiva.
